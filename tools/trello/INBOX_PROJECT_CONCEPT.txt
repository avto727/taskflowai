# Концепция: Inbox + Project (Trello)

## Идея

**Inbox (Todoist)** - быстрый сбор задач
**Project (Trello)** - структурирование больших проектов
Связка двух систем через наш backend

## Разделение ответственности

- **Todoist** = задачи, дедлайны, рутина (что делать сегодня)
- **Trello** = проекты, этапы, планирование (что делать в целом)

## Workflow

1. Быстрая идея → Inbox (Todoist)
2. Разбор inbox → создание задач ИЛИ проекта
3. Большая задача → Project (Trello) с декомпозицией
4. Задачи из Trello → синхронизация в Todoist

## Примеры использования

### Простая задача
- Inbox: "Купить молоко" → Todoist (категория Быт)

### Средняя задача
- Inbox: "Сделать ремонт" → Trello проект "Ремонт квартиры"
- Колонки: Планирование → В работе → Готово
- Карточки: Спальня, Кухня, Ванная
- Чеклисты в карточках → задачи в Todoist

### Большой проект
- Inbox: "Запустить стартап" → Trello board "Стартап"
- Колонки: Идея → MVP → Тестирование → Запуск
- Карточки с подзадачами
- Дедлайны карточек → задачи в Todoist

## Технические возможности

### Синхронизация
- Trello карточка с дедлайном → Todoist задача
- Todoist задача с parent_id → Trello чеклист
- Двусторонняя синхронизация статусов

### ИИ помощь
- Анализ inbox: "Это задача или проект?"
- Предложение структуры проекта
- Автоматическая декомпозиция

### Правило семи мешков
- Большая цель → Trello проект
- 7 этапов (мешков) → 7 карточек
- Каждая карточка → чеклист задач
- Задачи → синхронизация в Todoist

## Что добавим

### Backend
- Trello API интеграция (уже есть в tools/kaiten)
- Эндпоинты для синхронизации
- Маппинг: Trello card ↔ Todoist task

### Bot
- /inbox - быстрое добавление
- /review - разбор inbox с ИИ
- /project - создание проекта в Trello
- /sync - синхронизация Trello ↔ Todoist

### Web App
- Канбан доска (Trello-like)
- Переключение: Tasks (Todoist) ↔ Projects (Trello)
- Drag & drop между системами
