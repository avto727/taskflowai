# Концепция TaskFlowAI (Irga New)

> **Для кого:** Разработчики и архитекторы  
> **Что внутри:** Архитектура, философия, план развития по этапам  
> **Отличие от README:** README — для пользователей (как установить и использовать), description.md — для разработчиков (почему так сделано и куда двигаться)

## 💡 Идея проекта

> **"Инфраструктура — их. Интеллект — наш."**

Берём проверенный backend (Todoist) — хранение, синхронизация, надёжность.  
Добавляем свой мозг (Irga) — анализ, автоматизация, проактивность.  
Создаём новый продукт — умнее, быстрее, удобнее.

**Аналогия:** Todoist — это двигатель. Irga — это автопилот. TaskFlowAI — это Tesla.

## Философия

**"Не изобретаем велосипед — улучшаем его."**

### Принципы:

1. **Используем готовое** — Todoist решает хранение, синхронизацию, UI
2. **Добавляем интеллект** — Irga решает ИИ-анализ, автоматизацию, проактивность
3. **Создаём ценность** — пользователь получает лучшее из двух миров
4. **Локальная приватность** — ИИ работает локально (Ollama), в Todoist только результат
5. **Множество клиентов** — один backend, много интерфейсов (Telegram, Web, Mobile)

### Слои системы

#### 1. Todoist Integration Layer

**Ответственность:** Работа с Todoist API

**Компоненты:**
- `todoist/client.py` — клиент для Todoist API
- `todoist/mapper.py` — маппинг категорий Irga ↔ Todoist
- `todoist/crud.py` — CRUD операции

**Маппинг категорий:**
- 5 основных категорий Irga → 5 проектов в Todoist
- 50 подкатегорий Irga → метки (labels) в Todoist

**Пример:**
```
Irga: Деньги / Оплата счетов
  ↓
Todoist: Project "💰 Деньги" + Label "Оплата счетов"
```

#### 2. Irga Layer

**Ответственность:** Умные функции (из Irga Old)

**Компоненты:**
- `irga/ai_processor.py` — ИИ-анализ текста через Ollama
- `irga/smart_linking.py` — умное связывание задач
- `irga/time_scheduler.py` — умное планирование времени
- `irga/proactivity.py` — проактивные напоминания

**Функции:**
1. **ИИ-анализ текста:**
   - Определение категории из 55 вариантов
   - Определение статуса (план/в процессе/выполнено)
   - Извлечение даты и времени

2. **Умное связывание:**
   - Поиск похожих задач перед созданием
   - Предотвращение дубликатов
   - Автоматическое обновление статуса

3. **Умное планирование:**
   - Подбор свободного времени по режиму дня
   - Автоматическое распределение задач

4. **Проактивность:**
   - Утренние сообщения с планом на день
   - Вечерние напоминания о просроченных
   - Аналитика продуктивности

#### 3. API Layer

**Ответственность:** REST API для клиентов

**Эндпоинты:**
- `POST /auth/login` — авторизация
- `GET /tasks` — получить задачи
- `POST /tasks` — создать задачу
- `PUT /tasks/{id}` — обновить задачу
- `DELETE /tasks/{id}` — удалить задачу
- `POST /ai/analyze` — ИИ-анализ текста
- `GET /categories` — получить категории

**Технологии:**
- FastAPI (рекомендуется) — быстрый, async, автодокументация
- Flask — проще, но медленнее

#### 4. Clients

**Ответственность:** Интерфейсы для пользователей

**Варианты:**
1. **Telegram Bot** — тестовый клиент (Этап 2)
2. **Web App** — основной клиент (Этап 3)
3. **Mobile App** — нативное приложение (Этап 4)
4. **Browser Extension** — быстрое добавление (Этап 5)

## Технические решения

### Backend Framework

**Рекомендация: FastAPI**

**Почему:**
- ✅ Быстрый (async)
- ✅ Автодокументация (Swagger)
- ✅ Современный (type hints)
- ✅ Легко тестировать

**Альтернатива: Flask**
- Проще для начинающих
- Медленнее
- Меньше возможностей

### Хранение данных

**Основное хранилище: Todoist**
- Задачи, проекты, метки

**Дополнительное хранилище: SQLite/PostgreSQL**
- Метаданные Irga (если нужно)
- Кэш для быстрого доступа
- История ИИ-анализа

### ИИ-модель

**Ollama + Qwen 2.5:7b**

**Почему:**
- ✅ Локальная (приватность)
- ✅ Бесплатная
- ✅ Быстрая
- ✅ Хорошо понимает русский язык

### Авторизация

**Вариант 1: Todoist OAuth**
- Пользователь авторизуется через Todoist
- Получаем его API token
- Работаем от его имени

**Вариант 2: JWT**
- Свои пользователи
- Хранят Todoist token у нас
- Больше контроля
