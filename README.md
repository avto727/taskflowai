# TaskFlowAI (Irga New)

> **"Инфраструктура — их. Интеллект — наш."**

Умный таск-менеджер на базе Todoist с ИИ-автоматизацией от Irga.

## 💡 Идея

Берём проверенный backend (Todoist) — хранение, синхронизация, надёжность.  
Добавляем свой мозг (Irga) — анализ, автоматизация, проактивность.  
Создаём новый продукт — умнее, быстрее, удобнее.

**Аналогия:** Todoist — это двигатель. Irga — это автопилот. TaskFlowAI — это Tesla.

## Установка

### Требования

- Python 3.11+
- Аккаунт Todoist (бесплатный или платный)
- Ollama с моделью qwen2.5:7b (устанавливается автоматически)

### Автоматическая установка

```bash
git clone <repository>
cd irga_new
python install.py
```

Скрипт установки:
- ✅ Создаст виртуальное окружение
- ✅ Установит зависимости
- ✅ Поможет настроить Todoist
- ✅ Создаст файл конфигурации `.env`
- ✅ Проверит установку Ollama

### Настройка Todoist (выполняется во время установки)

1. **Регистрация:** https://todoist.com → "Sign up" → "Continue with Google"
2. **Создание проектов:** 💰 Деньги, 👨👩👧👦 Семья, 💪 Здоровье, 💕 Отношения, 📚 Развитие
3. **API token:** https://todoist.com/app/settings/integrations → "Для разработчиков" → скопировать токен

### Запуск

**1. Запустить Backend API:**
```bash
source .venv/bin/activate  # Linux/Mac
python backend/api/main_api.py
```

**2. Запустить Telegram Bot (в другом терминале):**
```bash
source .venv/bin/activate  # Linux/Mac
python clients/telegram/simple_bot.py
```

**3. Открыть бота в Telegram и начать работу!**

**Команды бота:**
- `/start` - главное меню
- `/auth` - авторизация (ввод Todoist токена)
- `/logout` - выход из аккаунта
- `/tasks` - список задач с группировкой по дням
- `/subtask` - создать подзадачу
- `/projects` - проекты Todoist (5 категорий жизни)
- `/delete` - удалить задачу
- `/help` - помощь

**Кнопки меню:**
- 📋 План на сегодня
- 📅 План на завтра
- 🔄 Перенос просрочки (автоматически на сегодня)
- ✏️ Редактировать (v2.0)

**Умные запросы:**
- "Ирга, план на сегодня" - задачи на день
- "Ирга, план на завтра" - задачи на завтра
- "Ирга, план на неделю" - задачи на неделю
- "Что по здоровью?" - фильтр по проекту
- "Что по деньгам?" - фильтр по проекту

**Возможности v1.0:**
- ✅ Подзадачи с иерархией
- ✅ Автоматический перенос просроченных задач
- ✅ Фильтрация по датам (сегодня/завтра/неделя)
- ✅ Группировка задач по дням
- ✅ Отображение времени выполнения
- ✅ AI-анализ текста для категоризации
- ✅ Мультипользовательская авторизация

## Терминология Todoist

**Структура:** Project (проект) > Section (секция) > Task (задача) > Subtask (подзадача)

Ирга использует терминологию Todoist. Для совместимости поддерживается старое название "категория" = "проект".

- Telegram-бот с локальной SQLite базой

- Умное связывание, проактивность

**TaskFlowAI (Irga New):**
- Backend на базе Todoist API
- Сохранение всех умных функций Irga
- Множество клиентов (Telegram, Web, Mobile)
- Синхронизация на всех устройствах
