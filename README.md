# TaskFlowAI

> **"Умный помощник для ваших задач"**

ИИ-бот для управления задачами через Telegram. Работает с вашим Todoist аккаунтом.

## 🚀 Что это?

TaskFlowAI — это Telegram бот, который делает работу с задачами проще:
- 🤖 **Понимает естественный язык** — пишите как удобно
- 🕐 **Умное планирование времени** — "утром" = 6-12 часов
- 📅 **Группировка по дням** — Сегодня, Завтра, конкретные даты
- 🔄 **Переносит просрочку** — одной кнопкой на сегодня
- 📋 **Группирует по дням** — как в Todoist, но удобнее

## 🚀 Как начать пользоваться

### Что нужно:
- Аккаунт Todoist (бесплатный подойдет)
- Telegram на телефоне

### Первые шаги:

1. **Зарегистрируйтесь в Todoist:**
   - Перейдите на https://todoist.com
   - Нажмите "Sign up" → "Continue with Google"
   - Создайте 5 проектов: 💰 Деньги, 👨👩👧👦 Семья, 💪 Здоровье, 💕 Отношения, 📚 Развитие

2. **Получите API токен:**
   - Откройте https://todoist.com/app/settings/integrations
   - Найдите раздел "Для разработчиков"
   - Скопируйте токен (длинная строка из букв и цифр)

3. **Найдите бота в Telegram:**
   - Напишите @TaskFlowAI_bot (или как называется ваш бот)
   - Нажмите `/start`
   - Выполните `/auth` и вставьте токен из пункта 2

4. **Готово!** Теперь можете создавать задачи просто написав боту

## 📱 Как пользоваться

### Создание задач:
Просто пишите боту что нужно сделать:
- "Купить молоко завтра утром" → создаст задачу на завтра в 6-12 часов
- "Встреча с врачом в 15:30" → создаст на сегодня в 15:30
- "Заплатить за интернет" → создаст без времени

### Управление задачами:
- **📋 План на сегодня** — показать задачи на день
- **📅 План на завтра** — показать задачи на завтра  
- **🔄 Перенос просрочки** — перенести все просроченное на сегодня
- `/tasks` — все задачи с группировкой по дням
- `/delete` — удалить задачи по номерам
- `/subtask` — добавить подзадачу

### Умные команды:
- "Покажи план на сегодня"
- "Что по здоровью?" — задачи из проекта Здоровье
- "Удали задачи 5 и 7" — удалит несколько задач сразу

## 🌟 Области жизни

Бот автоматически определяет область жизни и создает задачу в нужном проекте Todoist:

- 💰 **Деньги** — зарплата, покупки, счета, инвестиции
- 👨👩👧👦 **Семья** — дети, родители, встречи, праздники
- 💪 **Здоровье** — врачи, спорт, питание, лекарства
- 💕 **Отношения** — друзья, коллеги, общение, мероприятия
- 📚 **Развитие** — обучение, книги, хобби, саморазвитие

## ❓ Поддержка

Если что-то не работает:
1. Проверьте что токен Todoist правильный
2. Убедитесь что создали 5 проектов в Todoist
3. Попробуйте перезапустить бота командой `/start`

## 🔧 Команды

- `/start` — главное меню
- `/auth` — подключить Todoist
- `/tasks` — все задачи
- `/projects` — проекты (категории)
- `/subtask` — создать подзадачу
- `/delete` — удалить задачи
- `/help` — помощь
